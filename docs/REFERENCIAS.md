# Mr. Tatú — Referencias

Material de briefing (el CEO ya lo buscó). Aquí se **abstrae** qué copiar como idea y qué no copiar como marca.

Mockup de trabajo: [assets/home-mockup.jpg](assets/home-mockup.jpg)

## Qué confirma el sector (Bogotá y estudios actuales)

| Idea | De dónde sale | Qué hacemos con eso |
|------|---------------|---------------------|
| Oscuro funciona | Práctica habitual de estudios | Paleta `#080808` + un acento |
| No esconder el siguiente paso | **Crisbo Tattoo** (cotizar → portafolio → redes) | CTAs fijos: Ver portafolio / Cotizar |
| Portafolio por estilos | **Supremacy Tattoo** | Filtros Blackwork, Realismo, B&G, Fine line, Color, Cover up |
| Identidad personal + estilos + cotizar, sin parecer tienda genérica | **Cintia Tattoo** | Artista y proceso antes de empujar merch |
| Formulario estructurado (idea, zona, tamaño, refs) | Estudios que profesionalizan la consulta | Cotización ≠ «mándame un DM» |
| Redes como experiencia, no un ícono en el footer | Sitios actuales del gremio | Bloque SIGUENOS + feed |
| Masonry de proporciones distintas | Galerías de estudio, no grilla e-commerce | HU-031 |

---

## Qué no copiar

- Logo, nombre, fotos ni copy de Crisbo / Supremacy / Cintia / del mockup si las piezas no son nuestras.
- El black+red de plantilla «tattoo WordPress» a pantalla completa.
- Números de otro artista (años, cantidad de tatuajes).

---

## Assets para el demo (cuando se pida HU-013)

Usar solo:

- Fotos con licencia clara (Unsplash / Pexels / propias) de tatuajes y de un artista trabajando.
- Merch en fondo negro (camiseta, gorra, hoodie) — placeholders.
- Marca **Mr. Tatú** inventada.

Marcar en cada pieza demo: «contenido de muestra, reemplazable».
